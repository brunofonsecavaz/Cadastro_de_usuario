# Sistema de Cadastro de Usuário

Sobre o projeto

A ideia foi criar uma aplicação simples de cadastro e trabalhar a comunicação entre uma aplicação React e uma API.

Foi um dos projetos que usei para estudar melhor como funciona a divisão entre frontend e backend, criação de rotas, requisições e persistência de dados com banco de dados.

A aplicação permite realizar o cadastro e gerenciamento de usuários através de uma interface feita em React. O frontend se comunica com uma API desenvolvida em Node.js, responsável por processar as requisições e trabalhar com o banco de dados.

Frontend

React + Vite.

Responsável pela interface que o usuário utiliza para realizar as operações de cadastro e consultar os dados.

Backend

Desenvolvido utilizando Node.js, com Prisma ORM para comunicação com o banco de dados.

A API recebe as requisições feitas pelo frontend, realiza o processamento necessário e salva ou consulta as informações no banco.

## Tecnologia utilizada

* JavaScript
* React
* Vite
* Node.js
* Prisma ORM
* SQLite
* API REST
